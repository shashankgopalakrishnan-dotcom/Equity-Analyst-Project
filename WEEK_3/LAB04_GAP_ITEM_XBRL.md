# Gap item: Why XBRL tags and periods matter

A tag is a label that tells a computer what a reported number means. A company can use a different tag in a later year because it changes how it presents an item, or because it uses a more specific label. So, do not choose a number by tag name alone. Check what the tag means and which filing and period it comes from.

The period end must match the 10-K's fiscal year end. If it does not, the number may come from an older year or from a shorter period. Comparing it with this year's figures can give a wrong result.

**In one sentence:** “The label can change when the company changes how it reports an item, so I check the tag's meaning and use numbers that end on the same fiscal year date as the 10-K.”
